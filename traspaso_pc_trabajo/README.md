# Traspaso al PC de trabajo

Rama **congelada**: no se fusiona con `develop` ni recibe más desarrollo.

Su intención es una sola: poder leer, desde el PC de trabajo recién reinstalado, el material preparado mientras
ese equipo no estaba disponible. Reúne lo necesario para retomar el entorno de desarrollo y para plantear a
Informática un servidor de desarrollo dedicado: qué se pide, cómo sería el flujo de trabajo y una síntesis del proyecto
para presentarlo.

Es material de apoyo de lectura e impresión, no documentación viva del proyecto.
